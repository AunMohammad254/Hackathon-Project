## ✨ Why This Project?

Built during a hackathon, this platform leverages **cutting-edge AI** to empower healthcare professionals and patients alike. By automating repetitive tasks, providing intelligent diagnostic suggestions, and ensuring seamless communication, we aim to modernize the clinical experience.

<br/>

## 🚀 Key Features

| Feature | Description |
| :--- | :--- |
| 🛡️ **Role-Based Access** | Tailored and secure portals for **Patients**, **Doctors**, **Admins**, and **Receptionists**. |
| 🤖 **AI Smart Diagnosis** | Powered by Google Gemini AI. Includes drug interaction alerts, lab report analyses, and a dynamic health chatbot. |
| 📄 **Automated Records** | On-the-fly PDF generation and parsing to maintain comprehensive, portable health histories. |
| ⚡ **Modern Next.js UI** | A fully responsive, accessible, and fast frontend built with Next.js, Tailwind CSS, and Shadcn UI. |
| 🔒 **Robust Backend API** | Node.js/Express architecture paired with Supabase for rock-solid authentication and data storage. |

<br/>

## 📁 Repository Structure

```graphql
Hackathon-Project/
├── 🎨 frontend/        # Next.js App Router, React, Tailwind, Shadcn UI
│   ├── src/app/        # Role-based routes (admin, doctor, patient, receptionist)
│   └── src/components/ # Reusable UI & AI integration components
└── ⚙️ backend/         # Node.js, Express, TypeScript API
    ├── src/controllers/# Business logic & API endpoints
    ├── src/services/   # Gemini AI integration, PDF generation, Supabase
    └── src/routes/     # RESTful route definitions
```

<br/>

## 🛠️ The Tech Stack

### 🎨 Frontend
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS & Shadcn UI
- **Language:** TypeScript

### ⚙️ Backend
- **Server:** Node.js & Express.js
- **Database & Auth:** Supabase (PostgreSQL)
- **AI Integration:** Google Gemini API
- **Docs:** Swagger (OpenAPI)

<br/>

## 🏁 Getting Started

Dive into the code and get the system running locally:

### 1. Backend Setup
Navigate to the backend directory, install dependencies, configure your `.env`, and start the server. 
👉 **[Read the Backend Documentation](./backend/README.md)**

### 2. Frontend Setup
Navigate to the frontend directory, install dependencies, and launch the Next.js development server.
👉 **[Read the Frontend Documentation](./frontend/README.md)**

### 3. Launch
Once both servers are running, open your browser and visit:
> **`http://localhost:3000`**
